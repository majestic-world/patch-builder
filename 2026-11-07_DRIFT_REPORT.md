## README.md

- The Build description says it zips only `New` and `Changed` files and that `Unchanged` Archives remain reusable. During a CRC32-only to BLAKE3-containing migration, `build::run` also schedules an `Unchanged` file when its existing Archive cannot prove the scanned BLAKE3 digest, so the status-limited description is incomplete. [`README.md:System Overview`, `README.md:Global Invariants`, `README.md:Global Side Effects`; `src/build.rs:run`]

Exported Slint contracts such as `AppWindow`, `TreeRow`, `SummaryView`, `ComparisonCard`, and `Theme`, plus the release-console API exported by `BuildConsole.psm1`, have no EGM contract or equivalent interface inventory. ## src/README.md

- The Source invariant says the tree contains regular files, but `scan::walk` rejects symbolic links and descends into directories without rejecting other non-directory file types. The implementation does not enforce the documented regular-file restriction. [`src/README.md:Invariants`; `src/scan.rs:walk`]
- The CRC32-to-BLAKE3 migration rule is absent: Scan verifies the decompressed BLAKE3 digest of otherwise unchanged Archives, and Build may re-zip those files even though their comparison status is `Unchanged`. This affects comparison semantics, Build work, and progress totals. [`src/scan.rs:run`, `src/scan.rs:archive_matches_blake3`, `src/build.rs:run`]
- The Interface inventory omits module-public contracts that callers inside the binary use: `BuildError`/`io_at`, the four display formatters, Manifest constants/path/error helpers, `Plan` state-transition methods, `show_error`, and the detailed tree row/sort API. These symbols are implemented but not represented as interface entries.
